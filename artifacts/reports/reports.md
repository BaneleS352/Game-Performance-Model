# `artifacts/reports/` Folder Guide

## Folder purpose

Stores notebook-driven predictions and stakeholder/model reports.

## File inventory

| Pattern | Purpose |
|---|---|
| `current_predictions.pkl` | Current scored forecast rows. |
| `model_business_report.xlsx` | Notebook-generated Excel report. |
| `reports.md` | Folder guide. |

The upload pipeline stores auditable run reports under `artifacts/uploads/<run_id>/`.
