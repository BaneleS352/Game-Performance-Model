# `src/game_performance_ml.egg-info/` Folder Guide

## Folder purpose

Generated setuptools metadata for the editable/installable project. It is not a
runtime source module and should be regenerated by packaging tools when project
metadata changes.

## File inventory

| File | Purpose | Dependencies | Description |
|---|---|---|---|
| `PKG-INFO` | Distribution metadata | setuptools | Name, version, dependencies, and long description. |
| `SOURCES.txt` | Source manifest | setuptools | Files included in the generated distribution metadata. |
| `requires.txt` | Dependency metadata | setuptools | Runtime and optional dependency declarations. |
| `top_level.txt` | Top-level package names | setuptools | Declares `game_performance`. |
| `dependency_links.txt` | Dependency link metadata | setuptools | Usually empty for this project. |
| `game_performance_ml.egg-info.md` | Folder guide | Markdown | Documents generated packaging metadata. |

## Key processes

`pip install -e .` or another setuptools build refreshes these files. Developers
should change `pyproject.toml`, not generated metadata directly.
